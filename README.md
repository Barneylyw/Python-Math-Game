# Python-Math-Game
A little multiplication game that my friend and I created for a high school project

## How to play
Run the code; the controls and information are displayed on the terminal, while the visual graphics are displayed in a separate window

It will load for ~5 seconds, then it will tell you who you are and what you need to do

You are in a fight with the turtle monster; your sword is helping you by asking you math questions and will deal damage accordingly

There will be a multiplication question (max 13 x 13); the quicker you answer, the more damage you will do to the monster. If you answer it incorrectly, you'll get a debuff.

However, if you don't answer with a number, the sword will start to have its own will; you might need to try that function to see what it will do. :)

The code has not been modified since high school; there are (probably) spelling/grammatical mistakes.
